# 幸福工厂服务器租用：4核8G够几个人？配置要求、端口、费用与购买流程一次讲清

幸福工厂的存档有个特点：玩得越久越难分享。三个人约好晚上一起扩建，结果主机那台电脑白天在公司、晚上要渲染自己那一份画面，其他人进来就是看幻灯片。租一台专用服务器解决的就是这件事——把模拟和渲染拆开，让工厂在你不上线的时候也照常运转。

下边按「需要什么配置 → 端口怎么给 → 花多少钱 → 怎么下单」的顺序讲，能省掉你反复试错的那几个晚上。

## 先搞清楚：你租的到底是什么

幸福工厂的专用服务器是官方单独提供的一个免费工具，不跟游戏客户端捆绑。Steam 库里把筛选切到「工具」就能看到 Satisfactory Dedicated Server；Linux 上用 SteamCMD 拉，App ID 是 1690800。

所以租金买的从来不是软件，是硬件和网络。三件事得先分清楚：

| 联机方式 | 花钱吗 | 需要什么 | 主要问题 |
| --- | --- | --- | --- |
| 点对点（P2P） | 免费 | 主机玩家保持在线 | 主机的机器同时跑渲染和模拟，工厂一大帧率掉、tick 也掉 |
| 自建专用服务器 | 免费 | 一台 24 小时开机的机器 + 可用的公网端口 | 要自己走 SteamCMD、配防火墙、处理端口 |
| 租用专用服务器 | 月付 | 一台云服务器 | 前期要花一点时间配置，换来 24 小时在线 |

国内玩家真正卡住的通常是第二条：家里那台电脑没有公网 IPv4，端口映射也未必做得通。这就是「租」最直接的理由。

## 幸福工厂真正吃的是什么

一个反直觉的点：**玩家人数对负载的影响很小，工厂复杂度才是那个变量。** 一条几百小时的存档里，传送带、无人机、电网、火车路线全在服务器侧持续运算，单人玩巨型工厂比四人玩新档重得多。

社区和多份托管指南给出的规模对应关系大致是这样：

| 工厂阶段 | 内存 | CPU | 硬盘占用 |
| --- | --- | --- | --- |
| 前期（T1–T4，探索为主） | 4 GB | 2 核 | 10 GB |
| 中期（T5–T7，mk2–mk4 传送带） | 8 GB | 4 核 | 15 GB |
| 后期（T8+，核电、火车网络） | 12–16 GB | 4 核以上，主频要高 | 20 GB |
| 巨型工厂（多个生态区全开） | 16–24 GB | 单核越快越好 | 25 GB 以上 |

> 官方文档给的下限是 8 GB 内存，存档较大或超过 4 人建议 16 GB。社区维护的 Docker 镜像则把最低写成 12 GB、推荐 16 GB。两个数字不冲突：8 GB 是「能启动、能跑一个年轻工厂」，12–16 GB 才是留出成长空间的位置。

CPU 这里别按常规思路挑。幸福工厂的生产 tick 基本是单线程的，物流和车辆寻路有一点并行，但主体是串行模拟。**核心数翻倍几乎没用，主频提上去才有效。** 同样价钱在「更多核」和「更快核」之间犹豫时，选更快的核。

硬盘也留点余量：服务端本体就要十几个 GB，长期跑下来存档会明显变大，另外自动存档写入慢会带来周期性卡顿——云盘是 NVMe 的话这一项基本不用操心。

## 端口这件事，比想象中麻烦

幸福工厂不走 HTTP，常规的 Nginx / Caddy 反向代理对它完全没用，玩家是直接连 IP 加端口的。常被引用的端口组合：

- `7777/UDP`：游戏主流量
- `15777/UDP`：服务器查询
- `15000/UDP`：Beacon
- 另有资料提到 `8888/TCP` 用于可靠消息

最容易踩的坑是：**官方不支持把标准端口做重定向，外部端口必须和内部端口一致。** 你不能把 7777 对外映射成 25565 再指望联机成功。只有可靠消息端口可以用 `-ExternalReliablePort=` 改。

雨云用户的幸福工厂开服教程里，`run.sh` 使用的游戏端口是 25306，其余是 15777 和 15000。这说明不同渠道拿到的服务端打包默认值并不统一，**一切以你自己启动脚本里的端口为准**，然后照着在后台建端口映射。

还有一个只有实测才知道的细节：有雨云用户教程明确提醒过，江苏宿迁节点存在封 UDP 的情况，而幸福工厂主要跑 UDP。选区域时优先考虑宁波、镇江这类 BGP 节点；下单前顺手问一句客服当前的端口策略，比开完服才发现连不上要省事。

## 开服后最容易踩的四个坑

**端口内外必须一致。** 后台建端口映射时，外部端口别自己改个性化数字，和内部端口对齐。这是幸福工厂最容易卡住新服主的地方。

**管理员密码就是工厂的命。** 幸福工厂用的是首次连接认领流程：客户端 Server Manager 里添加服务器 → 设置管理员密码完成认领。拿到这个密码的人可以拆建筑、踢人、改游戏状态。密码丢了，得删掉 `ServerSettings.sav` 重新认领，代价是服务器侧设置清空（存档本身还在）。

**Auto Pause 要不要关，得想清楚。** 打开时空无一人服务器会暂停世界，省 CPU，适合碎片化开黑；关掉的话，第二天上线能看到满仓的容器，但服务器全天在跑模拟，配置不够时会拖慢一切。

**模组必须双端同版本。** 服务器装了 SML 和模组，每个进服的玩家客户端也要装同版本。最常见的事故是游戏更新后客户端升了、服务器没升，然后谁也进不去。装模组之前，先把一份纯原版存档下载回来。

存档本身也值得单独备份一次。幸福工厂的存档很大，默认 300 秒自动保存比较稳，间隔调到 120 秒以下反而会因为写盘带来规律性卡顿。准备动一条铝生产线或者装新模组之前，从 Server Manager 下载一份存档，比指望自动保存的轮转保留更靠谱。

## 常见问题

**幸福工厂一定要租服务器吗？** 不一定。两三个人作息一致、主机电脑常开，P2P 完全够用。租服务器的价值出现在这三种情况：主机经常不在线、工厂已经大到主机扛不住、或者队伍跨时区。

**8G 内存能玩到哪一步？** 官方下限就是 8 GB，跑到中期、几台机器加基础物流没问题。核电、全图火车、几千个建筑的时候，你会开始遇到掉线和存档写入时的卡顿，那时候升到 12–16 GB 更实际。

**雨云面板能一键开幸福工厂吗？** 目前公开的教程走的是 MCSM 面板加纯环境这条路线。如果你倾向一键开服，先确认面板当前的模板列表里有没有幸福工厂。

**大陆节点需要备案吗？** 雨云官方页面提到的是「大陆网站或常用端口的 HTTP 业务需要先经过域名备案 + 过白后才能使用域名访问」，这条针对的是建站场景。游戏服是玩家用 IP 加端口直连，不涉及建站那套域名流程。有合规方面的疑问，直接开工单问客服最准。

**买错了配置能改吗？** 可以。雨云的游戏云支持随时升级、降级和弹性变配，数据备份也在支持范围内。所以起步配置不用一次买到位——按「三个月后工厂会长到哪」选，就已经够前瞻了。

真正难搬的从来不是配置，是存档。选机器的时候多花十分钟，比三个月后带着几百小时的工厂数据换平台要轻松。
